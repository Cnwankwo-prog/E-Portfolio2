Unit 2: Frequency Analysis Using R

Overview

This unit developed my understanding of frequency analysis in R. I used the COVID-19 dataset to create a binary variable showing whether each daily state report recorded any recovered patients. I then produced a frequency table and calculated the percentage of reports within each category.

Learning Outcomes

  • Create a new binary variable from an existing numeric variable.
  • Use conditional logic through the ifelse() function.
  • Create and interpret frequency tables in R.
  • Convert frequency counts into proportions and percentages.
  • Explain statistical outputs clearly.

Task 1: Creating a Binary Variable

I created a new variable named has_recovery using the following R command: 

covid$has_recovery <- ifelse(covid$Cured > 0, 1, 0)

The ifelse() function checked each value in the Cured column. Reports containing one or more recoveries were assigned a value of 1, while reports containing no recoveries were assigned a value of 0. This converted the recovery information into a binary yes-or-no variable.

Task 2: Creating a Frequency Table

I used the following command to count the number of observations in each category: 

table(covid$has_recovery)
Category Meaning Frequency
0 No recoveries recorded 215
1 One or more recoveries recorded 55

The frequency table showed that most daily state reports did not yet contain any recovered patients. There were 215 reports with no recoveries and 55 reports with at least one recovery.

Task 3: Calculating Percentages

I converted the frequency counts into percentages using: 

round(prop.table(table(covid$has_recovery)) * 100, 2)
Category Percentage
No recoveries recorded 79.63%
At least one recovery recorded 20.37%

The results indicate that 79.63% of the daily state reports recorded no recoveries, while 20.37% recorded at least one recovery. This reflects the early stage of the COVID-19 outbreak in India between January and March 2020, when recoveries were still relatively uncommon.

Skills Demonstrated

  • Creating new variables in R.
  • Applying conditional logic using ifelse().
  • Producing frequency tables using table().
  • Calculating proportions with prop.table().
  • Converting proportions into percentages.
  • Interpreting and communicating statistical findings.

Reflection

This activity improved my understanding of how raw numeric data can be transformed into categories that are easier to summarise and interpret. Creating the binary variable helped me see how conditional logic can be used to answer a specific analytical question.

I also developed a clearer understanding of the difference between frequencies, proportions and percentages. In response to the formative feedback received for Unit 1, I included the output of each key command, explained what the command did and provided a short interpretation of the results.
