Unit 6: Database Analytics Design Group Project

Group Project

As part of a group project, we developed an AI-assisted database analytics solution using a healthcare readmission dataset. The project involved data profiling and validation, relational database design, normalisation, SQL analysis and the development of a proposed analytical dashboard.

The activity strengthened my understanding of how database design, data quality and AI-assisted tools can be combined to support the analysis of complex datasets. It also developed my experience of working collaboratively as part of a virtual project team.

Learning Outcomes: LO2, LO3 and LO4.

Tutor Feedback

The group project achieved a mark of 85%. The feedback highlighted the strong context and scope of the work, detailed database development, excellent prototyping and modelling, and excellent presentation. One area for further development was to link the rationale for using AI tools more explicitly to the methodology.

Reflection on Feedback

The feedback demonstrated that the project successfully applied database design concepts to the healthcare dataset and communicated the proposed solution clearly. It also identified an important area for improvement: ensuring that the rationale for selecting AI tools is linked more explicitly to the methodology. I will apply this learning in future work by explaining not only which tools were used, but why they were selected and how their use supports the chosen analytical approach.
