Unit 3: Data Collection and Storage

Overview

This unit explored different sources of data, methods of data collection and the challenges associated with collecting, verifying and storing information. Particular emphasis was placed on data integrity, fact-checking, web services, crowdsourced data and the memory and storage requirements of different data formats.

Learning Outcomes

  • Analyse different data sources.
  • Verify the integrity and reliability of data.
  • Apply appropriate data collection methods.
  • Conduct fact-finding and fact-checking.
  • Understand memory and storage requirements.
  • Evaluate the use of web services and crowdsourced data.

Required Reading

McKinney (2022), Chapter 7

This reading developed my understanding of data cleaning and preparation using Python. It introduced techniques for identifying and handling missing values, removing duplicate records, transforming data and preparing datasets so that they can be analysed more reliably.

Sardar and Pandey (2024)

This reading reinforced the importance of selecting reliable data sources and maintaining data quality throughout the collection and storage process. It also highlighted the challenges created by increasingly large and complex datasets, including the need for appropriate and scalable storage solutions.

Practical Activity: Web Scraping Using Python

For this activity, I used Google Colaboratory to create and run a Python web-scraping script. The script used the Requests and Beautiful Soup libraries to retrieve and parse information from the Wikipedia Data Science webpage.

The script searched the webpage paragraphs for the keyword "Data Scientist". Matching paragraphs were extracted, stored in a Python list and then saved in a JSON file so that the information could be reused or analysed later.

Aim

The aim of the activity was to create a Python script that could access a webpage, search its content for a selected keyword and save the matching results in a structured JSON format.

Libraries Used

  • Requests: used to send HTTP requests and retrieve the webpage.
  • Beautiful Soup: used to parse and search the webpage HTML.
  • JSON: used to save the extracted information in a structured file.

Key Python Commands

!pip install requests beautifulsoup4
import requests
from bs4 import BeautifulSoup
import json
url = "https://en.wikipedia.org/wiki/Data_science"
headers = {
    "User-Agent": "Mozilla/5.0"
}

response = requests.get(url, headers=headers)
soup = BeautifulSoup(response.text, "html.parser")
keyword = "Data Scientist"
results = []

for paragraph in soup.find_all("p"):
    text = paragraph.get_text(" ", strip=True)

    if keyword.lower() in text.lower():
        results.append(text)
data = {
    "url": url,
    "keyword": keyword,
    "results_found": len(results),
    "results": results
}
with open("data_scientist_results.json", "w", encoding="utf-8") as file:
    json.dump(data, file, indent=4)

Challenges and Problem-Solving

The initial HTTP request returned a 403 Forbidden response. This meant that the website was refusing the automated request.

I resolved this by adding a User-Agent header to the request so that it was recognised as coming from a web browser. After this change, the request returned a 200 OK status code, confirming that the webpage had been accessed successfully.

Reflection on the Web Scraping Activity

Completing this activity improved my understanding of how data can be collected automatically from online sources using Python. I gained practical experience using the Requests and Beautiful Soup libraries to retrieve webpage content and convert unstructured HTML into structured data.

The initial 403 response demonstrated that web scraping does not always work immediately and may require troubleshooting. Adding the User-Agent header helped me understand how websites identify requests and why some automated requests may be blocked.

I also learned that web-scraping scripts depend on the structure of a webpage. If the HTML structure changes, the script may need to be updated. The activity reinforced the importance of respecting website policies, avoiding excessive requests and ensuring that private or copyrighted information is not collected inappropriately.

Collaborative Discussion 1

The collaborative discussion ran across Units 1, 2 and 3. My initial post in Unit 1 explored the rationale behind the Internet of Things (IoT) and considered the opportunities, limitations, risks and challenges associated with large-scale data collection.

During the later stages of the discussion, I reviewed the contributions of other students, provided constructive peer responses and used the wider discussion to develop my final summary post.

Peer Responses

Engaging with my peers' contributions allowed me to consider additional perspectives on the opportunities and risks associated with IoT data collection. My responses considered issues including data quality, privacy, cybersecurity, data governance and the measures organisations can use to reduce the risks associated with collecting and processing large volumes of data.

The peer-review process encouraged me to move beyond simply identifying problems and consider how organisations could address them. This included considering preventative measures such as automated data validation, continuous monitoring, appropriate security controls and stronger governance arrangements.

Summary Post

My final summary brought together the main points from my initial post, the feedback generated through peer discussion and the learning developed across Units 1, 2 and 3.

The discussion reinforced my understanding that IoT can provide significant benefits through continuous and real-time data collection. However, simply collecting a larger volume of information does not automatically produce better decisions. The usefulness of the information depends on its accuracy, relevance, reliability and the way it is managed.

I also developed a greater appreciation of the importance of privacy, cybersecurity, data governance and ethical data collection. These considerations need to be addressed alongside the technical opportunities presented by IoT.

Reflection on the Collaborative Discussion

Participating in the collaborative discussion helped develop my critical-thinking skills by requiring me to evaluate viewpoints beyond my own initial contribution. Reading and responding to different perspectives encouraged me to consider areas that I had not explored fully in my original post and to support my responses with academic evidence.

The activity also demonstrated the value of peer learning. My understanding developed from initially focusing mainly on the benefits and risks of IoT towards considering the practical controls that organisations need to implement to manage these risks effectively.

Overall, the discussion strengthened my understanding that the successful use of large-scale data collection depends on more than technology alone. Data quality, security, governance, ethical considerations and appropriate management processes are all important in ensuring that collected data can be used safely and effectively.
