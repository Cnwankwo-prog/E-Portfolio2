Unit 3: Data Collection and Storage

Summary

Unit 3 focused on different sources of data, methods of data collection, data integrity and the challenges associated with storing and verifying information. The unit also explored web services, crowdsourced data and the importance of checking the reliability of data before it is used for analysis.

As part of the practical activity, I used Python in Google Colaboratory with the Requests and Beautiful Soup libraries to scrape information from the Wikipedia Data Science webpage. The script searched for the term "Data Scientist" and saved the matching results in JSON format.

The activity also required some troubleshooting. My initial request returned a 403 Forbidden response, which I resolved by adding a User-Agent header. The revised request returned a 200 OK response and successfully identified five matching results.

Overall, this unit strengthened my understanding of how unstructured online data can be collected and converted into a structured format, while also reinforcing the importance of data integrity, ethical collection and checking whether a source is suitable for analysis.
