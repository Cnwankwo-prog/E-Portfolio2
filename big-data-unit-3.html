Unit 3: Data Collection and Storage Overview This unit explored different data sources, methods of data collection and the challenges associated with collecting, verifying and storing data. Particular emphasis was placed on data integrity, fact-checking, web services and memory requirements for different data formats. Learning Outcomes Analyse different data sources. Verify the integrity and reliability of data. Apply appropriate data collection methods. Conduct fact-finding and fact-checking. Understand memory and storage requirements. Evaluate the use of web services and crowdsourced data. Reading Summary McKinney (2022), Chapter 7 This chapter introduced practical techniques for acquiring, cleaning and transforming data using Python. It demonstrated how Pandas can import data from multiple sources and prepare datasets for analysis through filtering, merging and reshaping operations. Sardar and Pandey (2024) The reading explained the importance of selecting reliable data sources and maintaining data quality throughout the collection process. It also discussed the challenges associated with storing increasingly large and complex datasets and the importance of scalable storage solutions. Practical Activity – Web Scraping Using Python During this activity I developed a Python web-scraping script using the Requests and Beautiful Soup libraries to retrieve information from the Wikipedia Data Science webpage. The script searched for the keyword "Data Scientist", extracted matching paragraphs and stored the results in a JSON file. The activity demonstrated how unstructured web content can be converted into structured data for later analysis. Initially, the script returned a 403 Forbidden response, which I resolved by adding a User-Agent header before sending the HTTP request. The completed script successfully returned a 200 OK response and identified five matching results. Skills Developed Python programming Requests library Beautiful Soup HTML parsing JSON Web scraping Data collection Data extraction Reflection Completing this activity improved my understanding of how data can be collected automatically from online sources. I also learned that web scraping depends heavily on webpage structure and that websites may reject automated requests unless appropriate request headers are provided. The exercise reinforced the importance of collecting data ethically and respecting website policies when scraping publicly available information.
