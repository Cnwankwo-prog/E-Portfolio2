Unit 1: Types and Sources of Data and an Introduction to R

Overview

This unit introduced the use of the R programming language to explore datasets and understand different data types. A COVID-19 dataset was used to investigate its structure, identify variables, convert dates and answer questions using basic R commands.

Learning Outcomes

  • Import a dataset into R.
  • Explore the structure of a dataset.
  • Identify variables and data types.
  • Convert character variables into dates.
  • Use descriptive statistics to answer questions.

Activity Completed

During this activity I imported the COVID dataset into R and used a variety of built-in functions to examine its structure. I identified the number of rows and columns, explored the variable names and data types, counted the unique states represented, converted the date variable into the correct format and identified the most frequently occurring state.

R Functions Used

  • nrow()
  • ncol()
  • names()
  • str()
  • summary()
  • length(unique())
  • as.Date()
  • range()
  • table()
  • which.max()

Key Findings

Question Answer
Total Variables 7
Total Observations 270
Numeric Variables 5
Character Variables 2
Date Variables 0 (before conversion)
Unique States 27
Date Range 30 January 2020 – 21 March 2020
Most Frequent State Kerala

Reflection

This activity increased my confidence in using introductory R functions to inspect and analyse a dataset. I developed a better understanding of how different variable types influence the type of analysis that can be performed and why converting data into the correct format is important before carrying out statistical analysis.

Following formative feedback, I recognised the importance of not only including the R commands used but also presenting their outputs and explaining what each command achieves. In future activities I will ensure that my work includes clearer interpretation of results alongside improved presentation.
