Unit 7: Constructing Normalised Tables and Database Build

Summary

This unit developed my understanding of database normalisation and relational database design. I normalised an unstructured student dataset through 1NF, 2NF and 3NF, identifying functional dependencies and separating the data into related entities using primary and foreign keys.

The activity demonstrated how normalisation reduces duplication, improves data integrity and supports the development of a structured relational database. My Excel workbook provides evidence of each stage of the normalisation process.
