Unit 3: Data Management in R

Overview

This unit developed my understanding of data management using R. It focused on reading data into RStudio, examining datasets and individual variables, converting variable types and understanding how missing values can be managed.

The practical activity used the COVID-19 India dataset from January to March 2020. I used R to create new binary and categorical variables, generate frequency tables and identify patterns in the data.

Learning Outcomes

Through this unit, I developed my ability to:

  • Read and examine datasets using R.
  • Examine individual variables within a dataset.
  • Create and convert different variable types.
  • Create binary and categorical variables.
  • Use frequency tables to summarise data.
  • Interpret patterns within real-world datasets.
  • Develop my understanding of how missing values can be managed in R.

Dataset Activity: COVID-19 India

For this activity, I used the COVID-19 India dataset, which contained 270 observations. The analysis focused on creating binary and categorical variables, producing frequency tables and identifying patterns within the dataset.

Death Reporting Analysis

I created a binary variable called has_deaths to identify whether any deaths had been recorded in each observation.

R Command

covid$has_deaths <- ifelse(covid$Deaths > 0, 1, 0)

table(covid$has_deaths)

Results

  • 245 records had no deaths reported.
  • 25 records had one or more deaths reported.

This demonstrated how the ifelse() function can be used to transform numerical information into a simple binary variable that can then be analysed using a frequency table.

Converting the Binary Variable to a Factor

I converted the numerical binary variable into a factor so that the two categories were easier to interpret.

R Command

covid$has_deaths <- factor(
    covid$has_deaths,
    levels = c(0, 1),
    labels = c("No Deaths", "Deaths Reported")
)

table(covid$has_deaths)

This changed the values 0 and 1 into meaningful categorical labels: No Deaths and Deaths Reported.

Classification of Confirmed Cases

I calculated the total number of confirmed cases by combining the confirmed Indian national cases and confirmed foreign national cases.

R Command

covid$total_confirmed <- covid$ConfirmedIndianNational +
    covid$ConfirmedForeignNational

I then created a categorical variable called case_level to classify the total confirmed cases into four groups. 

covid$case_level <- cut(
    covid$total_confirmed,
    breaks = c(-Inf, 0, 5, 15, Inf),
    labels = c(
        "No Cases",
        "Low Cases",
        "Medium Cases",
        "High Cases"
    )
)

table(covid$case_level)

prop.table(table(covid$case_level)) * 100

Results

Case Level Frequency Percentage
No Cases 0 0%
Low Cases 177 65.56%
Medium Cases 61 22.59%
High Cases 32 11.85%

The results showed that the majority of observations were classified as Low Cases. There were no observations with zero confirmed cases.

State and Union Territory Frequency Analysis

I used a frequency table to determine how often each State or Union Territory appeared within the dataset.

R Command

state_freq <- table(covid$State.UnionTerritory)

state_freq_sorted <- sort(
    state_freq,
    decreasing = TRUE
)

head(state_freq_sorted, 10)

Top 10 States by Number of Daily Reports

State / Union Territory Daily Reports
Kerala 52
Delhi 20
Telengana 20
Rajasthan 19
Haryana 18
Uttar Pradesh 18

Kerala appeared most frequently in the dataset, with 52 daily records. It is important to note that this represents the frequency of reporting within the dataset rather than the total number of COVID-19 cases in Kerala.

Data Visualisation

I created a bar chart to visualise the ten states or Union Territories with the highest number of daily reports.

R Command

par(mar = c(10, 5, 4, 2))

barplot(
    head(state_freq_sorted, 10),
    main = "Top 10 States by Number of Daily Reports",
    xlab = "",
    ylab = "Number of Daily Reports",
    las = 2
)

The visualisation made the difference in reporting frequency clearer, with Kerala showing a substantially higher number of daily records than the other states.

Reflection and Learning Outcomes

This activity improved my understanding of how R can be used to transform, categorise and summarise data. Using functions such as ifelse(), factor(), cut(), table() and prop.table() demonstrated how raw numerical data can be converted into meaningful categories and frequency distributions.

The activity also reinforced the importance of maintaining clear and well-organised data throughout the analysis process. Effective data management supports transparency, reproducibility and the reliable interpretation of analytical findings.

Overall, this activity supported the module learning outcomes by developing my understanding of mathematical and statistical concepts used in Data Science and demonstrating how these methods can be applied to a real-world dataset to identify patterns and support evidence-based decision-making.
