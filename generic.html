Evaluation of Unit 6 Project Proposal Against Unit 11 Final Project

The Unit 6 group project focused on designing an AI-supported relational database solution using a healthcare readmission dataset. The proposal established the database structure, identified opportunities for AI-assisted analytics and outlined how the data could support healthcare decision-making. The project achieved 85%, although tutor feedback highlighted the need to demonstrate a clearer relationship between AI tools and the proposed methodology.

The Unit 11 individual project built on this foundation by evaluating the database design and applying AI-assisted Python profiling, validation, feature engineering, SQL analysis and Power BI visualisation. A significant development was the identification of data-quality problems that had not been fully addressed in the initial proposal. Although the dataset contained no conventional missing values, further validation identified 2,754 conflicting patient identifiers and invalid date sequences affecting 47.5% of records. Consequently, records were classified as VALID, WARNING or QUARANTINED rather than automatically corrected.

The final project also demonstrated the practical application of AI tools. ChatGPT supported schema identification, while Gemini assisted with Python code generation in Google Colab. The generated outputs were reviewed and validated, addressing the feedback received in Unit 6.

Overall Evaluation and Areas for Improvement

The progression from Unit 6 to Unit 11 demonstrated the importance of moving beyond database design towards assessing the reliability of analytical outputs. Although the final project produced an interactive Power BI dashboard, substantial data-quality limitations meant that its findings required cautious interpretation.

If undertaking the project again, I would introduce data profiling earlier, establish validation criteria before developing analytical measures and document AI-assisted decisions more systematically. I would also prioritise testing the normalised database implementation and ensuring that dashboard indicators clearly distinguish validated records from those requiring further investigation.

This evaluation demonstrated that successful healthcare analytics depends not only on technical design and AI capabilities but also on data quality, transparency and human oversight.
