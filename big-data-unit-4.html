Unit 4: Data Cleaning and Transformation

Overview

This unit developed my understanding of data cleaning, transformation and preparation using Python and Pandas. The practical activities focused on examining raw survey data, improving variable descriptions, formatting outputs, identifying non-applicable values and examining data types before analysis.

I worked with the UNICEF survey datasets mn.csv and mn_headers.csv. The exercises demonstrated how metadata can be used to improve the interpretability of a dataset and why data should be examined carefully before cleaning decisions are made.

Exercise 1: Preparing the Data Files

I used Python in Google Colab to import and inspect the mn.csv and mn_headers.csv files using Pandas.

The mn.csv dataset contained 9,080 rows and 159 columns, while mn_headers.csv contained 209 rows and three columns.

The main dataset used abbreviated variable names, while the header dataset provided more understandable descriptions. For example, HH1 represented "Cluster number" and HH2 represented "Household number".

Initial inspection also highlighted possible data-quality issues, including missing values and columns containing mixed data types. This demonstrated the importance of understanding the structure and quality of a dataset before beginning further analysis.

Exercise 2: Replacing Headers with Readable Labels

In this exercise, I created a mapping between the abbreviated variable names in the main dataset and their corresponding descriptions in the header dataset.

The results showed that 150 of the 159 column headings were successfully matched, leaving nine unmatched variables. Rather than automatically removing these columns, I retained the original names so that they could be investigated before any decision was made about excluding them.

Examples of transformed headings included HH1 becoming Cluster number, HH2 becoming Household number and LN becoming Line number.

This demonstrated how Python can automate metadata matching and transformation, while also showing why the results of automated transformations need to be checked rather than assumed to be correct.

Exercise 3: Formatting Data

I then focused on improving the readability of the survey data. Some values within the Question column of the header dataset were missing, meaning that the full question could not always be used as the variable description.

To address this, I created a readable description using the full survey question where available and the shorter label when the question was missing.

I matched these descriptions with the corresponding values from the first survey record. This produced clearer outputs such as "Cluster number: 1", "Year of interview: 2014" and "Result of man's interview: Completed".

This exercise showed how formatting and metadata can make raw datasets much easier to interpret before further analysis is carried out.

Exercises 4 and 5: Examining Data Values and Data Types

The final part of the activity examined non-applicable NA responses and the data types stored across the dataset.

The analysis showed that every record contained at least one NA response, while NA occurred 606,612 times across individual values.

This highlighted an important data-cleaning consideration. In survey data, NA may indicate that a question was not applicable to a respondent rather than that the information is erroneous or genuinely missing. Automatically deleting all records containing NA could therefore remove valid data.

I also examined the data types across the 159 columns. The results showed:

  • 142 object columns
  • 15 integer (int64) columns
  • 2 floating-point (float64) columns

The large number of object columns may partly reflect text values such as NA, which can cause columns containing otherwise numerical information to be interpreted as text.

Key Learning

  • Importing and inspecting datasets using Pandas
  • Understanding dataset dimensions and structure
  • Using metadata to interpret abbreviated variables
  • Automating the replacement of column headers
  • Checking unmatched metadata before removing data
  • Formatting outputs to improve readability
  • Investigating non-applicable and missing values
  • Examining and interpreting data types
  • Recognising the importance of context in data cleaning

Reflection

This activity strengthened my understanding that data cleaning is not simply about removing missing values or changing variable names. Before making changes to a dataset, it is important to understand what the values represent and why apparent data-quality issues may have occurred.

The large number of NA responses was a useful example. Initially, it might appear appropriate to remove records containing missing information. However, examining the context showed that NA could indicate that a survey question was not applicable rather than that the data was incorrect. Removing these records automatically could therefore result in the loss of valid information.

The exercises also improved my appreciation of metadata. Replacing abbreviated variable names with readable labels made the dataset considerably easier to interpret, while the nine unmatched headers demonstrated that automated transformations still require validation.

Overall, this unit has helped me recognise data preparation as a critical stage of the analytical process. Reliable analysis depends on understanding the structure, meaning and quality of the underlying data before statistical or analytical methods are applied.
